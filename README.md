# Aid Assist

Build a professional AI-powered emergency healthcare severity assessment web application.

PROJECT TITLE:

"Automated Patient Severity Assessment from Emergency Healthcare Calls Using Natural Language Processing"

PURPOSE:

This application is designed as a decision-support system for emergency dispatch personnel. It should analyze information obtained from an emergency healthcare call and eventually classify the reported case into four severity levels:

- Critical

- High

- Moderate

- Low

IMPORTANT:

This is an academic AI & Data Science mini project. Do NOT present the system as a replacement for doctors, emergency professionals, or medical diagnosis. Clearly indicate that the prediction is only decision support and that final decisions must be made by qualified emergency personnel.

CURRENT DEVELOPMENT STAGE:

For now, create the complete frontend and application interface only. Do NOT create fake AI predictions or claim that an actual ClinicalBERT model or Speech-to-Text model is working. Prepare clean API integration points so that the real AI backend can be connected later.

TECHNOLOGY:

- React

- TypeScript

- Tailwind CSS

- Modern responsive UI

- Component-based architecture

- Clean and maintainable code

- Use a professional healthcare/emergency visual design

- Desktop-first but responsive for tablets and mobile
